System Architecture

Clean Layered Architecture

Strict separation of concerns across Presentation, Domain, Data, and Remote subsystems.

Presentation Layer (`dev.sequel.app.presentation`)

Composed entirely in declarative Jetpack Compose with Material 3 theming. ViewModels expose immutable StateFlow streams to Composables, ensuring Unidirectional Data Flow (UDF).

DetailViewModel.kt (State Pattern) 
// Observes Room Flow immediately without blocking UI on remote network
val uiState: StateFlow<DetailUiState> = combine(
    showRepository.getShowWithSeasons(showId),
    watchedEpisodeRepository.getWatchedEpisodesForShow(showId),
    reviewRepository.getReviewForShow(showId)
) { show, watched, review ->
    DetailUiState.Loaded(show, watched, review)
}.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), DetailUiState.Loading)

Domain Layer (`dev.sequel.app.domain`)

Pure Kotlin business logic completely insulated from Android framework dependencies. Houses Use Cases, repository contracts, and the sealed AppError hierarchy.

GetNextEpisodeUseCase.kt 
class GetNextEpisodeUseCase @Inject constructor(
    private val seasonRepository: SeasonRepository,
    private val watchedEpisodeRepository: WatchedEpisodeRepository
) {
    suspend operator fun invoke(showId: Int): EpisodeEntity? {
        val watched = watchedEpisodeRepository.getWatchedEpisodesList(showId)
        val allEpisodes = seasonRepository.getAllEpisodesForShow(showId)
        return allEpisodes.firstOrNull { ep ->
            !watched.any { w -> w.seasonNumber == ep.seasonNumber && w.episodeNumber == ep.episodeNumber }
        }
    }
}

Data Layer (`dev.sequel.app.data`)

Room Database (SQLite v17) serves as the Single Source of Truth (SSOT). Repository implementations coordinate local caching with background WorkManager uploads.

Remote Services Layer (`dev.sequel.app.data.remote`)

Coordinates communication with external APIs: Retrofit for TMDB v3 catalog queries and Ktor-based SupabaseClient for PostgreSQL storage and GoTrue authentication.

SupabaseSyncService.kt (PostgREST Upsert) 
suspend fun upsertWatchedMovie(dto: SupabaseWatchedMovieDto): String {
    val result = supabaseClient.postgrest["watched_movies"]
        .upsert(dto) {
            onConflict = "user_id,tmdb_movie_id"
            select(Columns.list("id"))
        }
        .decodeSingle<SupabaseWatchedMovieDto>()
    return result.id ?: throw IllegalStateException("Supabase did not return an ID")
}

Database & Cloud

Supabase DDL & RLS Policies

Production-grade PostgreSQL 15 schema ready for deployment in your Supabase SQL Editor.

user_watchlist.sql 
CREATE TABLE IF NOT EXISTS public.user_watchlist (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    tmdb_id INTEGER NOT NULL,
    media_type TEXT NOT NULL CHECK (media_type IN ('tv', 'movie')),
    title TEXT NOT NULL,
    poster_path TEXT,
    added_at BIGINT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT user_watchlist_unique UNIQUE (user_id, tmdb_id, media_type)
);

ALTER TABLE public.user_watchlist ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can manage their own watchlist"
ON public.user_watchlist FOR ALL
USING (auth.uid() = user_id)
WITH CHECK (auth.uid() = user_id);

reviews.sql 
CREATE TABLE IF NOT EXISTS public.reviews (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
    media_id INTEGER NOT NULL,
    media_type TEXT NOT NULL CHECK (media_type IN ('tv', 'movie')),
    season_num INTEGER,
    episode_num INTEGER,
    rating INTEGER CHECK (rating >= 1 AND rating <= 10),
    review_text TEXT,
    is_rating_only BOOLEAN NOT NULL DEFAULT FALSE,
    updated_at BIGINT NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE UNIQUE INDEX IF NOT EXISTS idx_remote_reviews_movie_unique 
ON public.reviews (user_id, media_id, media_type)
